The app

A media gallery built around exploration.

Aves-Next keeps the core strengths of Aves while continuing under a separate community identity and distribution path.

Browse collections

Explore albums, tags, places, countries, maps, search, filtering, and other views designed for large media libraries.

Inspect metadata

Work with the information embedded in image and video files instead of treating media as anonymous pictures.

Understand location

Use geographic and map-oriented features to explore media connected to places, coordinates, and paths.

Wide format coverageCommon and specialized image/video formats, including panoramic, motion, 360°, and GeoTIFF-oriented media.
Media managementFile operations, collection selection, bin/recycle workflows, and related actions.
Viewer controlsPlayback, metadata overlays, slideshow behavior, viewer settings, and media-specific controls.
Android integrationWidgets, shortcuts, global search, media viewer/picker functionality, screen saver handling, and Android TV support.
Under the hood

Flutter on Android, split into focused modules.

The repository is a Flutter application with native Android packaging and a set of local plugins that separate UI, services, media/video, maps, reporting, utilities, and model code.

Application stack

Dart + FlutterMain application and UI layer.
Android + GradleNative packaging and platform integration.
Flutter 3.47.0-0.3.preVersion pinned by the repository.
JDK 21 in CIModern Java toolchain for Android builds.

Local project packages

aves_magnifier aves_map · aves_model aves_report · aves_report_console aves_screen_state · aves_services aves_services_none · aves_ui aves_utils · aves_video · aves_video_exo · aves_video_mpv

These packages keep the main application from becoming one undifferentiated codebase.
