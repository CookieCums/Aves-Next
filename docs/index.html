A modern home for your media.

Aves-Next is a community-maintained continuation of Aves: a visual media gallery and metadata explorer for Android, built with Flutter and backed by a modular media, metadata, map, and video stack.

What the project does

Aves-Next focuses on the everyday work of exploring, organizing, viewing, and understanding large collections of photos and videos, while retaining the deeper metadata and location-oriented capabilities inherited from Aves.

▦

Browse collections

Navigate albums, tags, places, countries, maps, and other collection views designed for large media libraries.

⌁

Inspect metadata

Explore image and video metadata and work with the information embedded in media files.

◎

Understand location

Use geographic views and mapping features to explore media connected to places and paths.

Features inherited from Aves

The fork retains a broad feature set from the upstream application. The project is maintained as a separate distribution and identity.

Media galleryFast browsing of large photo and video collections.
Collection navigationAlbums, tags, places, countries, maps, search, and filtering.
Advanced formatsSupport for common and uncommon image/video formats, including formats used for panoramic, motion, 360°, and GeoTIFF media.
Media managementFile operations, collection selection, bin/recycle workflows, and related management actions.
Viewer toolsViewer settings, playback controls, metadata overlays, slideshow behavior, and media-specific controls.
Android integrationWidgets, app shortcuts, screen saver handling, global search, media viewer/picker functionality, and Android TV support.

Technology & architecture

The repository is a Flutter application organized around local packages and platform-specific Android integration. Focused plugins separate concerns such as maps, video, reporting, UI, utilities, and services.

Application stack

  • Dart + Flutter for the main application and UI.
  • Android + Kotlin Gradle DSL for native packaging and platform integration.
  • Flutter 3.47.0-0.3.pre pinned by the repository.
  • Android compile SDK 37 with JDK 21 in CI.
  • sqflite and Flutter-side services for persistent app data.

Repository modules

  • Media and video packages including ExoPlayer/MPV-backed integrations.
  • Mapping and vector-map packages for geographic views.
  • Metadata/media tooling including TIFF, SVG, MP4, and PixyMeta-related libraries.
  • Local plugins for reporting, screen state, services, UI, utilities, magnification, and model code.

Builds & distribution

Aves-Next currently produces two supported Android release flavors. Google Play Services/Firebase integration was removed from the supported build path, and the project is positioned for direct APK-oriented distribution.

Automated APK builds

GitHub Actions builds split-per-ABI release APKs for both supported flavors and verifies that all six APK outputs are present.

Direct distribution

The current project documentation points toward GitHub Actions artifacts, GitHub Releases/F-Droid-oriented distribution, and other direct APK channels rather than Google Play.

Release signing

The Android build supports local or CI-provided signing configuration, including PKCS#12 .p12/.pfx keystores.
